# 📋 일과 매니저 (가족 일과 관리 웹앱)

HTML · CSS · JS로만 만든 정적 웹앱이에요. 빌드 과정이 따로 없어서 GitHub에 올리고 Vercel로 바로 배포할 수 있어요. 모든 데이터는 **이 앱을 사용하는 기기(아이패드)의 브라우저 안에만** 저장돼요 (localStorage 방식 — 별도 서버나 로그인이 없어요).

## 폴더 구성

```
routine-app/
├── index.html   # 전체 화면 구조
├── style.css    # 디자인
└── app.js       # 동작 로직 (체크리스트, 통계, 관리자 모드 등)
```

3개 파일만 있으면 동작해요. 추가 설치(npm 등)가 필요 없어요.

## 1. GitHub에 올리기

이미 깃 저장소를 쓰고 있다면 평소처럼 커밋/푸시하면 되고, 처음이라면 가장 쉬운 방법은 웹에서 업로드하는 거예요.

1. https://github.com 에서 새 저장소(Repository) 생성 — 예: `family-routine-manager` (Public/Private 아무거나 OK)
2. 저장소 페이지에서 **Add file → Upload files** 클릭
3. `index.html`, `style.css`, `app.js` 3개 파일을 드래그해서 업로드 후 **Commit changes**

(터미널을 쓴다면)
```bash
cd routine-app
git init
git add .
git commit -m "일과 매니저 초기 버전"
git branch -M main
git remote add origin https://github.com/내계정/family-routine-manager.git
git push -u origin main
```

## 2. Vercel로 배포하기

1. https://vercel.com 에 GitHub 계정으로 로그인
2. **Add New → Project** 클릭 → 방금 만든 저장소 선택
3. Framework Preset은 **Other**(또는 자동 감지된 그대로) 두고 **Deploy** 클릭
   - 빌드 명령(Build Command), 출력 폴더 모두 비워둬도 돼요. 정적 파일이라 별도 빌드가 필요 없어요.
4. 배포가 끝나면 `https://family-routine-manager-아무개.vercel.app` 같은 주소가 생겨요.

이후 GitHub 저장소에 새로 커밋/푸시할 때마다 Vercel이 자동으로 재배포해줘요.

## 3. 아이패드에 설치(홈 화면에 추가)

1. 아이패드 **Safari**에서 위에서 받은 Vercel 주소로 접속
2. 하단 공유 버튼(⬆️) → **홈 화면에 추가**
3. 홈 화면 아이콘으로 추가되면, 앱처럼 전체화면으로 실행돼요 (주소창 없이 깔끔하게 보여요).

## 사용 방법 요약

- **메인화면**: 자녀를 선택하고, 오늘 달성률·모은 스티커·보상 교환소를 확인해요. 날짜 칸을 누르면 오늘 날짜로 돌아오고, 양옆 화살표로 다른 날짜의 기록도 볼 수 있어요.
- **체크리스트**: 아침/귀가/저녁 탭에서 항목을 탭하면 완료 처리돼요. **세 시간대(아침·귀가·저녁)의 모든 일과를 다 완료한 날에만 스티커 1개**가 적립되고, 화면에 폭죽이 터지면서 완성을 축하해줘요. 완료 후 항목을 다시 취소하면 스티커도 함께 취소돼요.
- **보상 교환소**: 모은 스티커로 등록된 보상과 교환할 수 있어요.
- **통계**: 주간/월간 평균 달성률, 누적 스티커(하루 일과를 통째로 완료한 날의 수 + 부모님이 직접 준 스티커), 최대 연속 100% 달성일, 이번 주 일별 그래프, 가족 비교, 항목별 달성률을 볼 수 있어요.
- **설정(관리자 모드)**: 기본 비밀번호는 **0000** 이에요. 들어가서 바로 **비밀번호 변경**으로 바꿔주세요. 여기서 앱 제목, 자녀 정보, 스티커 직접 지급(선택한 자녀의 현재 보유 스티커가 함께 보여요), 하루 일과, 보상 목록을 관리할 수 있고, 데이터 내보내기/불러오기(백업), 전체 초기화도 할 수 있어요.

## 참고하면 좋은 점

- 데이터는 **이 기기의 이 브라우저에만** 저장돼요. 아이패드를 바꾸거나 브라우저 데이터를 지우면 사라지니, 가끔 설정 화면 하단의 **데이터 내보내기**로 백업해두는 걸 추천해요.
- 관리자 비밀번호는 암호화 없이 단순 저장돼요. 외부 침입을 막는 보안 장치가 아니라, 아이들이 설정에 실수로 들어가지 않게 막는 정도의 가벼운 잠금이에요.
- "최대 연속 달성일"은 그날 등록된 모든 일과를 100% 완료한 날을 기준으로 계산해요(최근 120일 기준).
